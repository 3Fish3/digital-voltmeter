# 掉电隔离范围与历史研究记录

## 现行决策与验收边界

采用“先烧录调试，再断开调试器，使用独立电源供电测量”的分阶段流程。掉电主板不长期连接带电SWD、串口及其他独立供电外设；核心板原USB不与独立测量电源并接。维持既有64元件草案，不新增隔离芯片，不要求核心板USB物理遮挡/隔断。未采纳的器件路线见[候选方案归档](poweroff-isolation-options.md)。

两路模拟输入限流钳位、电源防反接及双源互灌保护仍属硬件验收范围。PA0在VANA有电而3V3异常掉电时的注入、PA1储能及轨顺序、ADC数字接口的板内部分上电路径，仍需依据准确器件和实板测量验证；断开外设不能解决这些板内路径。此处保留验证任务，不预先指定新增隔离芯片。精度暂不冻结；共地低压测量，不是电气隔离或市电测量授权。

下文是决策变更前的研究记录，不再作为现行整改清单；当前待办以[V2.3评审P0表](V2.3-controlled-schematic-review.md#7-p0关闭条件)为准。

## 历史目标（已被上述决策替代）

原研究前提：本板掉电时仍允许有电的串口适配器和SWD保持连接，不依赖拔线或固件防护。该前提不再适用于当前方案。

当前V2.3未新增隔离器件，本文件不是整改已完成。保留其连接蓝图和ERC结果，先核验准确器件再修改。

## 历史研究边界（非现行整改要求）

| 边界 | 现有路径 | 整改要求 |
| --- | --- | --- |
| 串口RX | J6.2→M1.PA10 | 有电适配器不可通过RX给主控寄生供电；保持3.3V逻辑协议，不接受RS232电压 |
| 串口TX | M1.PA9→J6.1 | 外设输入侧上拉/保护结构也要检查，不能默认输入无注入 |
| SWDIO | J5.3↔M1.PA13 | 双向收发与turnaround兼容，不能直接替换为单向缓冲器 |
| SWCLK | J5.4→M1.PA14 | 调试器保持高电平时，掉电隔离及时钟边沿/频率需核验 |
| NRST | J5.5↔M1.NRST | 调试器开漏/推挽与外部上拉兼容，不能只隔离SWDIO就遗漏复位 |
| SWD电压感知 | M1.3V3→J5.1 | 区分真正VREF感知与廉价调试器3.3V电源输出；后者不可直连。需要实购调试器针脚功能资料，未知则禁止该供电脚接入 |
| 模拟监测PA0 | VANA→10k/10k＋1k→M1.PA0 | VANA存在、VDDA掉电时限制/隔离注入；开关导通阻值、漏电、采样电荷重新预算 |
| 基准监测PA1 | 3V3→TL431→1k→M1.PA1 | 同轨来源降低风险但不代表任意掉电时序安全；检查储能与轨顺序 |
| ADC数字正向 | STM32→AHCT三个A输入 | VANA异常掉电而3V3存在，输入容限/钳位与供电条件需核验；OE禁用只影响输出，不自动隔离输入 |
| ADC数字反向 | ADC DO→LVC→STM32 | 精确LVC型号Ioff与输入容限，区分VCC=0和棕断中间电压 |
| 两路信号输入 | 外部源→分压/钳位→VANA | 原4.7k条件DC上界仅限两路输入，不替代上述外设或故障供电路径 |
| 核心板自身USB | 核心板USB→模块电源轨 | 原USB实际线路及遮挡/断路仍需实板资料，不假定已隔断 |
| 可选OLED | J7电源与SCL/SDA | 若外部有独立供电/上拉，也须纳入；仅在确认为本板供电时限定该条件 |

## 历史候选筛选（未采纳）

研究带明确断电保护的双向总线/模拟开关，优先易手焊封装；串口可采用单向Ioff逻辑，SWDIO需双向方案。不得将74HC4066、通用BSS138电平转换板或单向LVC缓冲直接视为解决方案。

Ioff在VCC=0的额定只说明该测试点的泄漏，不能证明0<VCC<最小工作电压整个阶段安全。硬件电源有效控制若需要新增监控器，必须先证明掉电默认状态、输出有效范围、使能脚自身注入、阈值容差与延迟；不能用MCU GPIO“及时关闭”代替硬件保证。

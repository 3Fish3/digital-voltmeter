# 双通道数字电压表：项目最初目标

整理日期：2026-10-23（America/New_York）。本文保存项目出发点与需求来源；实现方案见[最新设计报告](design-report.md)，完成情况与问题见[当前进度](progress.md)。

## 1. 最初要完成什么

完成一台用于电子课程实验的双通道数字电压表：用 STM32 控制 ADC0832，测量两路共地的 0～5V 直流电压，进行显示、串口传输和采样平均实验，最终交付经过检查和样机验证的硬件、软件与实验记录。

最早的工程任务是在已有 KiCad 项目上复核连接、修正封装、整理原理图并完成 PCB。整机功能目标持续保留，具体电路由最新设计报告说明。

## 2. 原始功能与后续明确的课程约束

| 需求 | 目标与范围 | 来源与约定 |
| --- | --- | --- |
| 主控与 ADC | STM32；主信号必须使用 ADC0832 双通道、8位 ADC | 早期采用 STM32F103C8T6 Blue Pill；辅助监测可用 STM32 内部 ADC |
| 测量对象 | 两路 0～5V DC 单端输入，两路共地 | 原始目标；被测对象须允许共地 |
| 模拟前端 | 两路分别缓冲、调理和滤波，降低串扰 | 早期采用 MCP6002；具体阻容及保护电路随设计核验调整 |
| 输入阻抗 | 正常上电测量时每路 ≥1MΩ | 后续需求文档明确的课程约束，需通过端口负载测试验证 |
| 采集与上位机 | ≥20Hz 完整双通道帧，绘图与存储使用同一帧 | 后续明确的课程约束；ADC0832 顺序采样，记录通道时间差 |
| 降噪实验 | 五组不同平均次数，对比波动和响应速度 | 后续明确的课程约束；1、4、8、16、32为候选组数 |
| 本地显示 | OLED 显示两路电压 | 原始功能；当前工程只预留可选接口，其交付范围差异记录在进度文档 |
| 通信 | UART 与上位机通信 | 原始功能；帧格式、波特率与软件实现由后续设计落实 |
| 输入接口 | 两路外壳接口与模拟前端分区 | 早期选用面板 BNC，经短同轴线接 PCB 端子；机械实现需实物核对 |
| 供电 | 初始为稳定 +5V；后续明确独立 USB 与外部5V供电，并防回灌 | 独立 USB 允许使用合适适配器，核心板自身 USB 不与测量电源并接 |
| 装配 | 优先常见、可采购、易焊器件，直插优先 | 必要处允许易手焊贴片；具体料号与尺寸需确认 |

## 3. 精度目标的来源

ADC 在5.000V参考下的名义量化步长为 `5V / 256 = 19.53125mV/LSB`。这是 ADC 端的理想步长；前端衰减会改变折算到输入端的步长，整机误差还受参考、器件和校准影响。

2026-09-20 的 V1.0 交接及 2026-09-21 的 V1.1 报告建议：室温、预热、校准后，全量程误差约不超过 ±50mV。原文将其列为待验证建议。

后续设计出现 ±0.15V 提案，相比 ±50mV 放宽了误差范围；现有资料未确认最终验收精度。该差异保留为[进度中的 REQ-01](progress.md#3-问题与关闭条件)，不能在合并文档时自动选定一个数值。

## 4. 使用边界

本项目测量低压、共地、单极性直流信号。市电测量、电气隔离、负电压量程、12V/24V误接耐受及标准ESD认证不在已明确的课程目标内。≥20Hz 指完整数据帧速率，最高被测信号频率尚未指定。

目前约定先完成烧录调试，再断开带电调试器，使用独立电源测量；核心板原 USB 不与测量电源并接。输入限流钳位、电源防反接和双源防回灌仍需硬件验证。

## 5. 最终交付与验收

1. 硬件资料：可原生打开的 KiCad 工程、可读原理图、实际引脚与封装映射、完整 BOM、PCB 及制造文件。
2. 软件：ADC0832 双通道采集、校准与五组平均；UART 数据帧；上位机同步绘图和存储；OLED 原始功能的范围需落实。
3. 工程检查：ERC、网表一致性、PCB DRC、极性和实物尺寸核对，剩余问题有记录。
4. 样机实验：限流上电、0～5V量程与误差、输入阻抗、供电保护、帧率、噪声/响应及串扰测试。
5. 课程报告：设计依据、实验条件、原始数据、结果和未达到项，能追溯到相应硬件与软件版本。

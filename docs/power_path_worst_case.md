沿用[V2.1电源连接](power-front-end-review-v2.1.md)：USB-B→保险丝→IN1；外部端子→保险丝→AO3401A反接保护→IN2；MUX OUT→SYS_5V→核心板，另经1Ω至VANA。候选D0内部上拉，D1接地自动模式；ILIM=680Ω+20Ω。禁止电源入口直接并联。

## 旁路及数字候选

### 核心板USB

首选机械上让核心板原USB不可插入，下载走独立SWD、通信走TTL。需要确定外壳/挡板和实板USB路径，未完成之前不能宣称隔断。若需要物理断开VBUS，必须先核对模块并单独授权具体改装；不在软件里假定已切断，更不拆除未知器件。

### 使能网络：NPN隔离5V上拉

替代旧报告“PB12开漏直接拉5V OE”的未验证方案：

```text
VANA ─ 10kΩ ─ BUF_OE_N ─ AHCT125脚1/4/10
                    └─ Q_EN集电极
PB12 ─ 10kΩ ─ Q_EN基极 ─ 100kΩ ─ GND
Q_EN发射极 ─ GND
```

Q_EN候选2N3904，厂商/封装脚序未核验，暂按功能端子描述，不能填最终封装。PB12高才启用，复位高阻由基极100k下拉禁用；与旧开漏低有效软件语义不同。VANA最高5.25V时上拉电流约0.53mA；3.0V基极驱动按VBE=0.9V及电阻容差可提供约0.20mA，具有饱和驱动余量，但该VBE也是预算值，最终按准确晶体管核验。

- AHCT三个A输入候选各47kΩ下拉，避免STM32复位悬空；CS在ADC侧上拉VANA、CLK和DI下拉GND。每路驱动串100Ω候选，调整时序须计算。
- 第四路A接地、OE接VANA禁用，Y标NC；不能用悬空输入代替禁用。
- LVC1G125下行保持3.3V供电、5V容限和Ioff候选；低有效OE可接GND作为默认接收，ADC DO输入侧候选47k下拉，输出100Ω到PB11。实际芯片、负载和掉电条件再次核验。
- **NPN只解决OE电压域，不自动解决AHCT A端或其他路径的断电注入。** STM32有电而VANA无电时，A端也可能注入，需要电源有效联锁与具体器件额定。CS/OE电源恢复默认状态须按时序验证。

### SWD/TTL及电源监测

- SWD VREF仅读电压，不供电；TTL只有TX/RX/GND，绝不连接TTL的5V/3.3V供电脚。
- 此限制仍不阻断有电调试器/适配器通过信号脚向掉电主控注入。串联电阻只限流，不是零注入隔离；最终若支持“本板掉电而外设保持连接”，必须选择经资料核验的断电隔离器件或受控断接，当前BLOCKED。
- 新PA0监测VANA在VANA有电、3.3V异常掉电时可能通过STM32输入钳位寄生供电。PA1基准由3.3V供电降低一条风险，但并不能证明PA0安全。需独立的掉电工况和绝对最大额定核验。

## 测试波形清单与合格定义草案

| 工况 | 要记录 | 定稿前判断 |
| --- | --- | --- |
| USB/外部单独及两源 | VBUS、EXT_SAFE、SYS、VANA、3.3V、两源电流 | 正常工作符合器件工作范围；无源间持续反灌；阈值须按芯片泄漏/源接受能力制定 |
| 两源近等压、突降、拔插 | 两源电流、输出瞬态、CS/OE | 不交叉供电；回流电荷和峰值须有来源容限，不能规定虚构“零瞬态电流” |
| 反接外部端子，USB有/无 | Q的VGS/VDS、IN2负压、输入电流 | 芯片脚不超绝对最大值，故障功耗受控，恢复无损；测试先限流 |
| 无源，两路输入0/5V | VANA、SYS、3.3V、各输入/各钳位电流 | 与[保护报告](input_protection_circuit.md)一致；不得部分上电 |
| 外设保持有电，本板掉电 | SWD/TTL/监测端注入、电源残压 | 隔离有效；未锁定隔离前不能验收 |
| 全负载冷/热与启动 | 入口电压、路径压降、各芯片温升 | 270mA与0.25Ω等分配成立，否则重新计算，不剔除失败工况 |

“源间持续反灌”限值及短时回流峰值/电荷尚未制定，本稿不能作为安全验收书。用户已确认合适USB适配器供电即可，不要求电脑口；适配器/线缆和板端最低电压仍需锁定，不能因此保证任意充电器合适。继续原厂资料及渠道核验，冻结边界后再生成原理图草案。

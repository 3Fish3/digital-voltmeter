# V2.2设计决策与阻塞项

**版本：研究审查稿，不是生产定稿。** 本轮继续V2.1独立审查，未修改旧工程，未画新版原理图，未采购或安装工具。

## 1. 本轮明确的基线

- 固定STM32＋ADC0832双通道；正常测量0～5V、输入阻抗≥1MΩ、完整双通道帧≥20Hz；优先常见直插。
- 每路180kΩ串联、1.2MΩ下拉作为基线，10MΩ偏置预留DNP；基线不是已验收的0V端点。
- TPS2115APW自动选源保持候选；不擅自替换成机械开关，也不直接增加升压器。
- PB12不再直接接受5V OE上拉。NPN隔离OE成为待核验的准确功能网络。
- 用户已确认采用**B：辅助基准＋VANA监测方向**，允许新增基准和少量校准程序；准确TL431型号和参数仍需核验，不等于最终采购授权。
- 用户已确认USB使用合适适配器即可，不要求电脑口供电；板端最低电压和适配器/线缆规格仍需证明。
- 保护增加明确泄放路径作为候选，不把180k限流或MOSFET当成全系统反灌验收。

## 3. 本轮计算结论

- 180k/1.2M无偏置，1%电阻角点最低输入电阻1.3662MΩ。净漏电、实际源阻抗与低端削顶不包含在这个结论里。
- TL431参考监测与4.7k泄放候选加入后，全板峰值分配改为270mA、模拟支路22mA；旧250mA/20mA预算不能直接复用。
- 条件板端4.75V、输入路径≤0.25Ω、MUX0.15Ω、模拟1Ω/1%成立时，VANA_min=4.61978V，高端理想角点余量约260.7mV。
- 两路5V输入、180k/1%限流、4.7k/1%泄放、上钳位零压降并忽略其他芯片负载的DC模型，VANA残压上界约0.252912V。没有其他注入是前提，不等于所有芯片绝不部分上电。
- 理想辅助ADC比值取消共同VDDA和实际VANA变化；校准后的分配误差和仍未预算项决定最终准确度，不能用理想等式宣布±0.1V保证。
- 条件加和约134.6mV，遗漏动态/源加载/低端等项，不构成150mV验收已通过。

## 5. 下一步与决策边界

用户已确认辅助基准监测＋校准方向和适配器供电；无需再重复询问这两项。

尚需核对准确度验收值、实购ADC0832的厂家/丝印及Blue Pill实板。±0.15V只是提案，不是已批准要求。实板资料不足时可画功能受控草案，但不能据此冻结封装或保证旁路安全。

这不需要用户选择电阻微小细节，但新增接口行为、依赖和适用条件不能自动批准。待资料核验和上述取舍明确后可画带BLOCKED标记的受控草案；最终冻结和投板仍需P0关闭及实物验证，不将本轮文档数量当作电路完成度。

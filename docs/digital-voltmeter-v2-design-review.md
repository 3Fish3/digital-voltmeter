# STM32＋ADC0832双通道电压表：新版硬件设计审查报告

**版本：V2.0-R0，方案审查稿，非投板定稿**

本报告用于外部工程师审查：说明器件、连接、计算依据和设计取舍。旧工程不作为新版连接权威；本轮不改旧原理图/PCB、不下单。文中“候选”表示待核验、待审查，不是已经安全验证的采购或接线指令。尚未生成新版原理图、完成SPICE仿真或实物试验。

## 1. 需求与边界

| 项目 | 固定要求 |
| --- | --- |
| 主控 | STM32，建议使用已有STM32F103C8T6 Blue Pill核心板 |
| 转换器 | 必须ADC0832，8位、双通道 |
| 正常输入 | 两路0～5V单极性直流，允许展示电压变化 |
| 输入阻抗 | 正常上电测量状态每路≥1MΩ；需明确实际测试定义，不能只看某一电阻值 |
| 数据 | ≥20Hz完整双通道帧；绘图、存储使用同一帧 |
| 降噪实验 | 软件平均，5组不同次数，对比噪声与响应；硬件不能把响应滤得过慢而掩盖实验差异 |
| 接口 | 外壳两路独立输入接口，接口和前端分区，降低串扰 |
| 供电 | 新版独立USB入口与外部稳压5V，设计防回灌；不使用Blue Pill自身USB作为另一路供电入口 |
| 器件 | 优先常见、可采购、易焊器件；直插优先，必要处允许SOIC/SOT-23等贴片 |

不要求市电测量、电气隔离、负电压量程或12V/24V误接耐受。两路为**共地测量**，“分区隔离”在此指布局/接口分区，不是隔离放大器意义的电气隔离。两路被测设备必须允许共地；USB连接电脑后地也可能与电脑保护地关联。不同电位的两个地不能分别接入本板。

用户未指定最高信号频率，不额外增加高速示波器指标。≥20Hz刷新不是可无失真显示20Hz输入波形的保证。

## 2. 设计概览

```text
独立USB 5V ─┐
             ├─ 输入保护/电源选择/反向阻断 ─ SYS_5V ─ 主控与显示供电
外部稳压5V ─┘                                  │
                                               └─ 模拟供电处理 ─ VANA

CH1接口 ─ 高阻衰减＋小偏置＋限流/低漏电保护 ─ MCP6002A ─ RC ─ ADC CH0
CH2接口 ─ 高阻衰减＋小偏置＋限流/低漏电保护 ─ MCP6002B ─ RC ─ ADC CH1

STM32 CS/CLK/DI ─ 74AHCT125三路 ─ ADC0832
ADC0832 DO ─ 3.3V SN74LVC1G125 ─ STM32
所有正常信号共地；模拟/数字按回流路径分区，不任意切割地平面。
```

优先通过合理供电、低漏电输入、缓冲与布局让ADC0832稳定发挥，不以昂贵器件或过多芯片替代设计。8位分辨率是结构限制：5V参考下ADC端理想步长5/256≈19.53mV，多次平均不能无条件把它变成高精度ADC。

## 4. 单通道前端与连接

以下两路完全复制，不共用串联电阻或滤波节点。位号采用功能名，避免与旧板位号混淆。

```text
J_CH.1 SIGNAL ─ R_S=120k ─┬─ N_SENSE ─ 运放同相输入
                         ├─ R_G=1.2M ─ GND
                         └─ R_B=10M ─ VANA
J_CH.2 RETURN ─ GND

N_SENSE ─ 低漏电上/下钳位（候选，未冻结）
运放反相输入 ─ 运放输出（单位增益跟随）
运放输出 ─ R_ISO=220Ω ─ N_ADC ─ ADC通道
                         └─ C_ADC=100nF ─ GND
```

### 4.1 MCP6002 DIP-8引脚表

| 引脚 | 功能 | 连接 |
| --- | --- | --- |
| 1 | OUTA | CH1缓冲输出，接CH1 R_ISO；直接反馈到2脚 |
| 2 | INA− | 接1脚，反馈取在R_ISO前 |
| 3 | INA+ | CH1 N_SENSE |
| 4 | VSS | GND |
| 5 | INB+ | CH2 N_SENSE |
| 6 | INB− | 接7脚，反馈取在R_ISO前 |
| 7 | OUTB | CH2缓冲输出，接CH2 R_ISO；直接反馈到6脚 |
| 8 | VDD | VANA；100nF就近接到4脚回流 |

### 4.2 直流计算

令Gs=1/R_S、Gg=1/R_G、Gb=1/R_B，忽略漏电与输入电流：

- `V_SENSE = α·Vin + β·VANA`
- `α = Gs/(Gs+Gg+Gb) ≈ 0.8992806`
- `β = Gb/(Gs+Gg+Gb) ≈ 0.0107914`
- 理想增量输入阻抗 `Rin = R_S + (R_G || R_B) ≈ 1.19143MΩ`。

VANA=5V时，0～5V映射为约53.96mV～4.55036V；折算输入理想步长约21.72mV。三个电阻均按1%极限组合计算，理想增量Rin最小约1.1795MΩ，尚未计保护漏电、板面漏电和偏置电流。

**重要区别**：该网络带偏置，电流并非恒等于Vin/Rin。Vin=0时会从模拟供电向被测源注入约0.45µA；输入电流为 `(Vin−V_SENSE)/R_S`。因此必须请审查者确认≥1MΩ要求是增量阻抗，还是不允许主动偏置的被动输入阻抗。不能只测5V处再宣布全范围满足。

偏置优点是避免运放低端贴轨，缺点是被测源负载、偏置注入和额外换算。如果课程要求不允许这种输入结构，应改为无偏置分压并另行解决0V端点。约54mV低端余量不能直接凭其他供电/负载下的25mV摆幅规格保证。

### 4.3 钳位候选

候选下钳位：二极管阳极接GND、阴极接N_SENSE；候选上钳位：阳极接N_SENSE、阴极接保护吸收节点。只有在该节点具有明确吸收路径、不会使VANA/数字电源异常抬升时，才能将其接VANA。

目前不冻结二极管型号或宣布该钳位完整安全：

- 常见1N4148需按温度和反向电压核验漏电；高阻节点误差约`Ileak×(R_S || R_G || R_B)`。
- 该并联电阻约107.9kΩ；100nA漏电即可导致约10.8mV节点偏移，不能忽略。
- 低漏电二极管正向压降可能较高，不保证在运放内部保护动作前就接管电流。
- 断电但被测输入存在时，上钳位可能给电源寄生供电；串联120kΩ仅限制注入，不是自动消除反灌。
- 若没有完整吸收/阻断设计，要求先移除输入再断电只能作为操作限制，不能当作解决电路安全问题。
- 在0～5V正常范围，须核验保护件不发生非预期导通。

### 4.4 RC与采样建立

220Ω＋100nF候选时间常数22µs，独立单极点截止约7.23kHz。理想全幅阶跃建立到0.5LSB约需`ln(512)·τ≈137µs`；这里只是连续RC的估算，不包含ADC内部开关电容和运放动态。

这个RC主要为隔离电容负载、降低高频干扰，**不能用它宣称在20Hz输出下已经满足抗混叠**。若需进一步限制输入频带，须与原始采样率、平均方法和阶跃实验一起确定；避免在高阻节点直接加大电容而拖慢响应。

## 5. ADC0832 DIP-8连接

| 引脚 | 功能 | 连接 |
| --- | --- | --- |
| 1 | CS，低有效 | U3的1Y，经100Ω候选；ADC侧10kΩ上拉到VANA |
| 2 | CH0 | CH1 N_ADC |
| 3 | CH1 | CH2 N_ADC |
| 4 | GND | GND，模拟回流就近 |
| 5 | DI | U3的3Y，经100Ω候选；ADC侧100kΩ下拉 |
| 6 | DO | U4的A，见第6节 |
| 7 | CLK | U3的2Y，经100Ω候选；ADC侧100kΩ下拉 |
| 8 | VCC | VANA，就近100nF＋局部储能电容 |

ADC0832没有可独立供电的VREF引脚，参考随VCC。不能把外加2.5V基准直接接某个不存在的VREF针脚。实际采购型号的数据手册与引脚须再次逐项确认，避免混用ADC0831/0834/0838或其他厂商兼容料。

两路用单端选择、相对于GND转换；ADC内部复用通道，不是两路同时采样。成对采集、同帧存储满足软件同步要求，但必须说明通道间时间差。

## 7. 供电方案：本稿重点待审部分

### 7.1 共同边界与连接

- USB-B VBUS到USB输入保护支路；GND到系统地；D+/D−不连接数据网络，标NC。
- 外部端子1脚EXT_5V、2脚GND；进入反接/限流保护后到另一支路。
- 两路经双向隔离能力适当的电源选择结构到SYS_5V；不得直接相连。
- SYS_5V供核心板5V入口；模块板载稳压器产生3.3V供STM32、U4及可选OLED。
- 不额外并联一个未知3.3V稳压器到核心板3.3V输出。
- 核心板USB旁路需从机械或电路上限制，否则新版板防回灌会被绕过。
- SWD与USB-TTL不得又注入5V/3.3V；SWD电压参考口须标清。

电源选择芯片、MOSFET和反接保护尚未锁定，不在此提供未经验证的管脚接线。需核验体二极管方向、门极范围、反向阻断、热耗散、输入切换及启动；**单只MOSFET不必然提供双向断开能力**。

USB仅供电的设备不能默认任意电脑口在未枚举时都允许任意取电。审查需给出总电流预算和合适的USB供电源约束；如果必须从电脑标准数据口供电，应评估枚举或其他合规电源策略。

### 7.2 两路线比较

| 路线 | 连接 | 取舍 |
| --- | --- | --- |
| A，简化 | SYS_5V→低压降滤波→VANA | 易焊、元件少、无新开关噪声；VANA随USB/外部源漂移，必须保证工作下限 |
| B，独立模拟稳压 | SYS_5V→小功率升压→低噪声LDO约5V→VANA | 供电一致性可能较好；贴片、电感、纹波、启动及过冲风险更多，不宣称一定优于A |

推荐让审查者先比较最坏电压和噪声预算，再决定，不强行选B。TPS7A2050为路线B候选，不是已确定料号。其±1.5%输出容差本身在5V附近可能贡献约75mV比例误差，低噪声不是高参考精度；升压输出在全工况不得超过其允许输入范围。

若示意采用5V±1.5%的VANA，前端5V输入仍映射到低于VANA的节点，可提供高端余量；但这种假设仅供计算，路线A不能无依据套用此电压容差。VANA至少同时满足ADC、AHCT、MCP6002正常工作范围，实际下限与上限由各器件交集及前端余量决定，不能只检查其中一只。

### 7.3 为什么不采用简单替换

- 两只肖特基二极管OR很常见，但压降可能使ADC电源低于工作范围；须预算后才考虑。
- 5V输入经普通5V线性稳压器没有压差，不能保证稳定5V输出。
- 磁珠滤波主要处理高频噪声，不消除直流供电误差。
- 10Ω“代磁珠”会增加参考压降，不能无条件等效替换。

## 8. 布局、装配和可测性

1. 两路输入连接器靠各自前端，高阻节点短且分开，避免长平行线；远离CLK、串口、USB入口及升压热回路。
2. 模拟区、数字区、电源区分区摆放，连续地平面保证回流；不以分割地平面制造回流绕行。
3. ADC及运放去耦靠供电脚；芯片串联电阻贴近信号驱动源。
4. 高阻节点注意助焊剂残留、污染及湿度；需评估护环收益与实际工艺，不为护环盲目加复杂度。
5. 使用实际模块、端子和电容尺寸画封装；Blue Pill排距实测，不以“通用名称”推断尺寸。
6. 明确接口丝印：CH1/CH2、SIGNAL/GND、5V ONLY、OLED电源顺序、SWD电压参考。
7. 测试点：SYS_5V、VANA、3.3V、两路缓冲输出和ADC输入、CS/CLK/DI/DO、GND。高阻节点测量应说明探头阻抗，普通10MΩ表/探头会改变网络，不能忽略加载。

## 9. 性能预算与校准约定

| 项目 | 现有依据 | 待补证据 |
| --- | --- | --- |
| 输入阻抗 | 三电阻理想增量最坏约1.18MΩ | 保护/偏置/漏电、温度和输入电流全范围；课程定义 |
| 高端余量 | 5V参考时节点最高约4.55V | 电源实际范围、容差、运放输出及负载 |
| 低端余量 | 0V输入时节点约54mV | 运放误差、摆幅、泄漏及温度，不保证未削顶 |
| 分辨率 | 输入折算约21.72mV/步，VANA=5V假设 | 实际参考、有效噪声、校准残差 |
| 滤波 | ADC端RC候选22µs | SPICE稳定性、ADC动态采样、实物阶跃 |
| 供电误差 | ADC参考随VANA | 两路线预算及实测，不能以LDO噪声指标替代 |
| 串扰 | 分区、短走线、独立缓冲 | 一路阶跃/满量程变化对另一路的实测影响 |

近似数字换算：`Vin ≈ (VANA/α)·(Code/256−β)`；量化有区间误差，不能认为该公式精确恢复真实电压。推荐每路两点校准，记录零点和增益。即使程序本阶段暂缓，最终不能沿用旧的`Code×5/255`直接显示本前端输入值。

校准只补偿静态增益/零点，不消除供电动态漂移、非线性、漏电、串扰或量化。

## 10. 采样时序预算

候选五组平均次数1、4、8、16、32，正式实验组由课程验收确定。最大32次、20完整双通道帧/秒，需要至少1280次有效转换/秒；每次转换还含通道选择、建立和读出开销。

以100kHz时钟、每事务暂按24个时钟预算，数字事务约240µs；这是保守预算候选，不是已核实最终驱动帧长。若另加约150µs等待，每64次事务约25ms，理论上可在50ms帧周期内留余量。实际必要等待位置、ADC允许时钟占空比和寻址建立必须按准确型号数据手册定型；加入丢弃转换后必须重新核算。

连续平均是否等效充分抗混叠取决于原始采样频率及分组方式，不能只凭“平均32次”宣称解决混叠。ADC不是硬件同步双采样，两路应成对交替读并记录时间偏差。

## 11. 验证计划

### 11.1 画图前

- 锁定ADC、逻辑、电源、保护准确料号及厂商数据手册，完成逐引脚对照。
- 明确输入阻抗定义、偏置注入是否允许、电源路线与总电流预算。
- 校验全器件工作范围、绝对最大值、上电/掉电、钳位吸收和寄生供电。
- SPICE验证可用模型的前端响应、负载稳定性及容差；无法建模的行为明确留实测，不伪造ADC模型。

### 11.2 原理图与PCB

- KiCad原生ERC、导出网表逐网络对照、符号/封装引脚一致性、视觉审查。
- KiCad原生DRC及原理图一致性，检查规则是否关闭或排除，零报告不等于零风险。
- 关键封装1:1尺寸核对与模块试装；不借警告抑制掩盖错误。

### 11.3 实物验收

| 试验 | 方法与通过条件 |
| --- | --- |
| 初次上电 | 断电检查短路/极性，限流电源分阶段上电；各电源和芯片符合正常工作范围 |
| 双源供电 | USB单独、外部单独、两者同时与拔插，测反向电流和启动/切换过冲；限值由具体电源器件冻结，不以“未冒烟”验收 |
| 断电输入 | 在正常0～5V范围内保留输入，测内部电源抬升和钳位/反灌；结果符合器件限制并无非预期寄生运行 |
| 输入阻抗 | 两路分别测多点输入电流、增量负载，并记录偏置注入；按课程认可的定义≥1MΩ |
| 量程 | 两路0V、0.1V、1V、2.5V、4.9V、5V；检查单调性、端点、校准前后误差及不提前削顶 |
| 噪声与响应 | 稳定源和阶跃，记录原始码、时间、平均次数；波动与响应数值目标待预算冻结 |
| 串扰 | 一路固定2.5V、另一路0/5V切换，交换两路重复；记录影响与供电变化，不预先宣称达标 |
| 采集 | 实测≥20完整双通道帧/秒，五组平均均有时间/序号记录，检查丢帧及通道时差 |

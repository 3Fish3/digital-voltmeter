### 2.3 关键计算与判断

**（1）ADC 供电滤波会影响测量比例**

TI ADC0832-N 数据手册给出参考与 VCC 内部相连，供电电流典型 2.3mA、最大 6.5mA。因此串 10Ω 时，估算压降为 23～65mV。若主电源恰为 5.000V，ADC 供电可能下降至约 4.977～4.935V。实际数值还取决于器件、时钟、负载及电源误差。[TI ADC0832-N 数据手册，第 2、5 页](https://www.ti.com/lit/ds/symlink/adc0832-n.pdf)

按该压降估算，满量程附近的比例变化可达约 0.46%～1.3%。固定偏差可能部分被标定吸收，随工况变化的偏差及高端削顶不能这样解决。

修改原则：主 5V 使用稳定电源；ADC 支路优先低 DCR 磁珠，例如把 DCR≤1Ω 作为初步选型约束，再核对频率阻抗、额定电流和实际纹波。保留 ADC 脚附近的 100nF 与 10μF。不能宣称磁珠消除了直流漂移。

**（2）分辨率、准确度和端点能力是不同概念**

名义参考为 5V 时：

- 1LSB = 5/256 = 19.53125mV。
- 理想量化误差通常以约 ±0.5LSB 表述，不代表整机误差只有 ±9.8mV。
- 增加显示小数位或平均次数不等于得到相应准确度。
- 换算采用实际校准关系 `V=a×code+b`；不要把 `code×5/255` 当成 ADC 理想传输规律。

MCP6002 的轨到轨输出仍有端点余量，其数据手册在指定负载、5.5V 供电条件下给出距电源轨约 25mV 的输出摆幅界限；不能把这个条件直接当成当前电路在 5.0V 下的保证值。器件也明确指出大电容负载可能影响稳定性。[Microchip MCP6002 数据手册，第 3、13～14 页](https://ww1.microchip.com/downloads/aemDocuments/documents/MSLD/ProductDocuments/DataSheets/MCP6001-1R-1U-2-4-1-MHz-Low-Power-Op-Amp-DS20001733L.pdf)

本方案可以先保留 MCP6002，但必须检查 0、0.02、0.05、0.10V 和 4.90、4.95、4.98、5.00V 附近的响应。若误差超过商定上限，需要调整模拟前端或供电/量程方案；单纯增加标定点无效。

**（3）±12V 保护方案有依据，但不能无条件保证**

以外部二极管压降约 0.7V 作粗估：

- 输入 +12V、5V 供电正常时，串联 10kΩ 电流约 `(12−5−0.7)/10k=0.63mA`。
- 输入 −12V 时，约 `(12−0.7)/10k=1.13mA`。
- 后一种工况下 10kΩ 电阻功耗约 13mW。

这些只是计算，不是实测。MCP6002 原厂给出了外接二极管加电阻的保护思路，并规定模拟输入的电压/电流限制，输入电流绝对最大值为 ±2mA；不能机械套用其他芯片常见的“只能超过电源轨 0.3V”规则。[Microchip MCP6002 数据手册，第 3、13 页](https://ww1.microchip.com/downloads/aemDocuments/documents/MSLD/ProductDocuments/DataSheets/MCP6001-1R-1U-2-4-1-MHz-Low-Power-Op-Amp-DS20001733L.pdf)

关键未闭合问题是上钳位向 5V 电源注入电流。稳压器不一定能吸收电流，断电时也可能反向供电。结论应为：**10kΩ+1N4148 可以保留作有条件的初版保护，但需验证二极管在实际电流/温度下的压降、所有输入应力和电源轨变化。** 不建议为了“更低钳位电压”盲目换成高漏电肖特基，影响高输入阻抗。

外壳暂只标“0～5V DC、共地、非隔离”；在保护试验完成前，不印“±12V 保证保护”。

**（4）DO 分压还需要检查输出驱动能力**

V1.2 中 10kΩ 上臂、20kΩ 下臂的方向正确。但 ADC0832-N 的 DO 在不同负载下有不同的高电平保证，不能始终假定为 5V。其较重负载条件下 VOH 最低 2.4V，直接乘 2/3 仅得 1.6V，这不足以完成保守的 STM32 输入裕量证明；这不等于每片实际都会输出 1.6V。[TI ADC0832-N 数据手册，第 5 页](https://www.ti.com/lit/ds/symlink/adc0832-n.pdf)

STM32F103 的 PB14 属于 FT 引脚，5V 容忍有配置和供电条件；不能把所有 3.3V 引脚一概视作同一种输入。[ST STM32F103x8/xB 数据手册，表 5、表 36](https://www.st.com/resource/en/datasheet/stm32f103c8.pdf)

**推荐用已经存在的 74AHCT125 第四路先缓冲 DO，再接原来的 10kΩ/20kΩ 分压。** 这样不增加 IC 数量，且可使用缓冲器确定的输出驱动参数核算。74AHCT125 的输入高电平门限为 2V，5V 逻辑供电范围为 4.5～5.5V。[TI SN74AHCT125 数据手册，第 5～6 页](https://www.ti.com/lit/ds/symlink/sn74ahct125.pdf)

例如按缓冲器全温较重负载条件的 VOH≥3.8V，配合 1% 电阻最小分压比 `19.8/(10.1+19.8)`，可得接收端高电平约 ≥2.52V，超过按 `0.65×3.6=2.34V` 取的保守接收门限。还须验证电源范围、边沿延迟、接收端输入漏电及上电时序。[TI 缓冲器电气特性](https://www.ti.com/lit/ds/symlink/sn74ahct125.pdf)、[ST I/O 电气特性](https://www.st.com/resource/en/datasheet/stm32f103c8.pdf)

补充：对于所查 TI ADC0832-N，控制输入 VIH=2V，故 3.3V 控制线并不是一律必须升到 5V。保留现有 AHCT 方案是本次减少改动的选择；其他厂商兼容器件需查对应手册。

## 三、修订后的设计报告技术正文（V1.3 建议替换稿）

以下内容替换原报告的核心技术参数、硬件方案、软件方案及实验章节。小组信息、分工、承诺书沿用原稿；不把设计目标改写成已完成结果。

### 3.1 系统与验收参数

本项目设计一台双通道、共地、非隔离的 0～5V 直流数字电压表，使用 STM32F103C8T6 Blue Pill 最小系统模块、ADC0832 8位双通道复用 ADC、MCP6002 双运放缓冲、OLED 显示和串口上位机。

| 项目 | 修订后的设计基线 |
|---|---|
| 量程与输入形式 | 两路 0～5V 单端直流；BNC 外壳接系统 GND |
| 输入阻抗 | 电阻网络名义约 10.01MΩ；整机在规定测试条件下验收 ≥1MΩ |
| 分辨率 | 名义 5V 参考下 19.53mV/LSB |
| 准确度 | 建议目标：25±5℃、预热和校准后 0～5V 内误差不超过 ±50mV；待教师确认及样机验证 |
| 模拟前端 | 每路 10kΩ 限流、10MΩ 对地、上下钳位、MCP6002 跟随器 |
| 模拟滤波 | 跟随器输出后串 3.3kΩ，ADC 端 1μF 对地；fc≈48.2Hz |
| 原始采样率 | 建议每通道 500 samples/s，即每秒 500 组双通道数据 |
| 转换时钟 | 建议从 100kHz 开始调试，按实际厂商数据手册满足时序 |
| 通道同步性 | 每周期连续采样两路，记录组时间戳及固定先后顺序；目标通道间隔 ≤0.5ms，实测确认 |
| 平均窗口 | N=1、4、8、16、32；默认 N=8，最终选择依据实验 |
| 正常上传及绘图 | 50 组/秒、约 50 次/秒；实际有效刷新不得低于 20Hz |
| OLED 刷新 | 10～20Hz，不阻塞采样 |
| 电源 | 稳定主 5V；Blue Pill 板载稳压器产生 3.3V；ADC 单独去耦支路 |
| 误接保护 | ±12V 为待验证的保护设计目标，不是测量量程或断电保护保证 |

50Hz 绘图仅是界面刷新指标，不代表 25Hz 以下任意波形均可高保真重建；本设备定位为直流及缓慢变化信号测量。

### 3.2 硬件设计

每路 BNC 芯线经 10kΩ 接输入节点，该节点以 10MΩ 接地，接 MCP6002 同相输入。上钳位二极管阳极接输入节点、阴极接主 5V；下钳位阳极接地、阴极接输入节点。反相输入仅直接反馈到本路运放输出。

运放输出与 ADC 输入必须是不同网络：两者之间串 3.3kΩ，1μF 接在 ADC 输入一侧对地。反馈不跨过 RC 电阻，两路使用相同结构与器件参数。该电阻也隔离运放与大电容负载。

ADC0832 的供电同时决定参考范围。默认采用低 DCR 磁珠、10μF 和 100nF 支路去耦，不把 10Ω 作为无需验证的等效替代。调试时测量 ADC 芯片供电脚处电压；建议把其稳定在约 5.00V 附近并控制变化，具体容差由误差预算与端点测试决定。

采用 74AHCT125 的前三路缓冲 CS、CLK、DI；第四路缓冲 ADC 的 DO 后，经 10kΩ/20kΩ 分压接 PB14。CS 控制侧设 10kΩ 上拉至 3.3V；CLK、DI 控制侧可各设 100kΩ 下拉；ADC DO/第四路输入加 100kΩ 下拉，避免 ADC 未选中时缓冲器输入悬空。PB14 使用数字输入，关闭内部上下拉。

USB-UART 默认连接 GND、TXD、RXD 三线，由其 USB 自行供电。接口电源脚默认不接；只有确认模块该脚为合适的电源输入或 VIO 参考后，才允许通过明确标注的跳线连接。不得并联两个未经设计的 3.3V 稳压输出。Blue Pill USB 与外部 5V 的共供电方式也需按实际模块核对。

PCB 保持连续参考地，缩短高阻输入走线，使数字时钟和显示电流回路远离模拟输入。接地包围作为屏蔽措施，配合清洁和干燥控制漏电。两路 BNC 共地，不是隔离输入；连接电脑后须考虑 USB 地的公共连接。

### 3.3 软件与通信

用定时器安排每 2ms 一组采样，两路连续转换，采样组序号和时间戳由 MCU 产生。原始数据进入各通道环形缓冲，采用运行和实现滑动平均，避免每次重复遍历整个窗口。显示、串口发送在独立调度中进行，不在采样中断内执行阻塞 OLED 或长字符串发送。

平均值保留小数精度，不先截断成 8位整数。N 变化时清空或正确重建窗口；窗口未填满时使用实际样本数或置无效标记。标定系数按通道独立保存，至少包含版本和校验。

正常通信使用 UART 115200bps、8N1。可采用：

```text
$D,seq,t_us,raw1,raw2,filtered1,filtered2,voltage1,voltage2,N,status*checksum\r\n
```

这里的 `\r\n` 表示实际回车换行，协议必须约定 checksum 算法、字段单位、小数精度和最大帧长度。建议正常模式每帧不超过 120 字节、每秒 50 帧，线路负载约不超过 6000 字节/秒。START、STOP、SET,AVG,N 均返回确认或错误，平均窗口仅接受指定集合。

正常模式可每 10 组采样上传一次选定时刻的原始值及滤波值；这不等于保存了全部 500Hz 原始数据。专属实验增加独立原始数据模式，例如 14 字节二进制帧：同步头 2、序号 2、MCU 时间戳 4、两路原始码 2、N 1、状态 1、CRC16 2 字节。500 帧/秒为 7000 字节/秒，可在 115200bps 8N1 容量内运行，仍需验证丢帧与缓冲。

上位机按帧同时写入两路值和 MCU 时间戳，界面绘图可降频；数据保存线程不得依赖绘图定时器。接收时间可另存，但不能替代采样时间。满量程码显示“边界/可能饱和”，不直接宣称已经精确检测到输入超过 5V。

### 3.4 专属实验与标定

固定每通道采样率 500Hz，先记录相同输入下至少 30秒原始数据，离线对同一数据分别计算五种窗口，再与 MCU 实时滤波交叉核对。额外各运行一组实时 N 设置，检验实际固件行为及刷新率。这样既避免五次输入状态不同造成偏差，也能证明实时实现有效。

| N | N/fs 窗口时长 | 理想滑动均值群延迟 (N−1)/(2fs) |
|---:|---:|---:|
| 1 | 2ms | 0ms |
| 4 | 8ms | 3ms |
| 8 | 16ms | 7ms |
| 16 | 32ms | 15ms |
| 32 | 64ms | 31ms |

此表为理论计算，不含模拟 RC、调度、上传与显示延迟。模拟 RC 时间常数为 3.3ms，理想 10%～90% 阶跃上升时间约 7.25ms；整个级联系统的上升时间应实测，不能简单机械相加。

每组统计均值、标准差、峰峰值、丢帧和有效更新率；对 1V↔4V 等阶跃测量 10%～90% 响应与进入规定误差带的稳定时间。响应试验使用 500Hz 记录或示波器，50Hz 界面不足以精细区分毫秒级差异。

平均对白噪声的改善依赖样本独立性；RC 后样本相关，不能保证严格按 1/√N 改善。固定 ADC 码也可能得到标准差为零，这不能证明分辨率提高。若比较工频抑制，应记录电网干扰频率及幅值；不要伪造或人为填入“预期”实验结果。

校准建议用 0.5V 与 4.5V 两点拟合，另测 0、1、2、3、4、5V 及端点附近小步进，避免只用已经饱和的两端建立系数。记录参考表读数、原始码、校准后值、误差、供电电压和温度。ADC 本身误差与理想量化项可能存在定义重叠，误差预算应解释采用的组合方式，避免重复计入同一项目。

### 4.2 P0：必须先修复的实际连线错误

#### S01：主电源 `5V` 与 `+5V` 没有连接

重建网络得到：

- `5V`：J6.1、C7.2、C8.2、FB1.1，以及值被改为 `5V` 的电源符号。
- `+5V`：U3.8、U2.14、J1.6、D1.K、D4.K、C5.1、C6.1。

这两组在文件中没有相连。按 J6 作为唯一主电源的方案，输入电源可经 FB1 到 ADC，但不能按设计给运放、逻辑缓冲器和 Blue Pill 正常供电。若外部 USB 另供电，可能掩盖此错误，不能视作通过。

**改法：将 J6.1 所在主电源统一为 `+5V`，其余位置保持完全相同名称；保留 `ADC_5V` 为独立滤波后网络。** KiCad 电源符号按其 Value 字段建立全局网络，`5V` 与 `+5V` 不会因为数值含义相似而自动连接。[KiCad 电源网络说明](https://docs.kicad.org/9.0/en/eeschema/eeschema.html#power-symbols)

`PWR_FLAG` 只是 ERC 的电源驱动声明，不会产生真实连接。当前断开的 `+5V` 网上已有 #FLG04，不能用它证明供电已经连通。

#### S02：ADC 的 DI 控制线断开

- Blue Pill 接口 J1.34：`ADC_DI_3V3`。
- 缓冲器 U2.9：`ADC_DI_3.3V`。

网络名不同，因此 MCU 指令无法沿预期路径进入缓冲器。统一为 `ADC_DI_3V3`，核对 J1.34 与 U2.9 同网。

#### S03：ADC 的 DO 返回线断开

- R7/R8 分压中点：`ADC_DO_3.3V`。
- Blue Pill 接口 J1.36：`ADC_DO_3V3`。

统一为 `ADC_DO_3V3`，核对分压中点与 J1.36 同网。若采纳修订后的第四路缓冲方案，先按 S08 调整 DO 驱动端。

当前 CLK 两端都使用 `ADC_CLK_3.3V`，所以**CLK 当前是连通的**；为避免再次混用，建议同时统一成 `ADC_CLK_3V3`，但不要把它误报为已断线。

#### S04：CH1 的 R5 两端被导线短接

当前同一导线网络内同时存在：

`U3.1、U3.2、R5.1、R5.2、C1.1、U1.2`。

因此 `BUF_CH1` 与 `ADC_CH1` 实际成为同一网，R5=3.3kΩ 被旁路。后果是没有设计的一阶 RC 低通，且 1μF 直接挂到运放输出。

正确关系：

- `BUF_CH1`：U3.1、U3.2、R5.2。
- `ADC_CH1`：R5.1、C1.1、U1.2。
- C1.2：GND。

这里使用当前 R5 的引脚朝向；普通电阻本身无极性。删掉从反馈网络延伸至 ADC 侧的旁路线，使两个节点只经 R5 连接。当前 CH1 的可疑桥接导线位于 `(64.77,81.28)` 到 `(64.77,88.90)`，可在编辑器中定位后高亮复核。

#### S05：CH2 的 R6 两端同样被导线短接

当前同网：

`U3.7、U3.6、R6.1、R6.2、C4.1、U1.3`。

正确关系：

- `BUF_CH2`：U3.7、U3.6、R6.2。
- `ADC_CH2`：R6.1、C4.1、U1.3。
- C4.2：GND。

第二路应重新整理反馈回路与 C4 的连接；不能仅删除一小段桥线，却把反馈留在电阻后或把 C4 留在运放输出侧。完成后检查 R6 两端为不同网络。

### 4.3 P0（制板前）：符号与封装错误

### 4.4 P1：按修订基线需调整或核实的项目

**S06：FB1 目前确实是 10R 电阻。** 应按 R01 改成选定的低 DCR 磁珠，或记录保留电阻的压降、参考稳定性和端点验证依据。

**S07：USB-UART 的电源脚接入系统 3.3V。** J5.1 目前与 J1.2、OLED 电源、I²C 上拉同网。若所购转换器的 3V3 脚是输出，会形成输出并联。默认断开 J5.1，采用 GND/TXD/RXD；确认模块原理图后再决定是否保留跳线。

**S08：使用 U2 第四路改善 DO 接口保证。** 当前 U2.12 接地、U2.13 接地、U2.11 有 NC，这种闲置处理本身正确；但修订方案将其改用于 DO 缓冲：

| 连接点 | 修订后的网络 |
|---|---|
| U1.6 与 U2.12 | `ADC_DO_5V` |
| U2.12 至 GND | 新增 100kΩ 下拉，避免 ADC 高阻时输入漂浮 |
| U2.13 | GND，保持使能 |
| U2.11 与 R7.1 | 新网 `ADC_DO_BUF_5V`，移除 U2.11 的 NC |
| R7.2、R8.2 与 J1.36 | `ADC_DO_3V3` |
| R8.1 | GND |

必须断开原 U2.12 的直接接地导线；不能在接地未解除时把 DO 接进去。R7=10kΩ、R8=20kΩ 保留。新增加的数字延迟应计入 ADC 读数时序验证。

**S09：MCU 复位期间控制输入没有外部默认状态。** 按修订稿为 CS 上拉、CLK/DI 下拉，并在固件初始化时先令 CS 无效、时钟低、再启动采样。

**S10：R9/R10 目前并未设 DNP。** 两者实际分别上拉 SCL/SDA 到 +3.3V，数值均为 4.7kΩ；导线正确。指导资料要求选装，但文件中的 `dnp=no`。根据 OLED 板载上拉确定是否安装，不应机械并联。

**S11：电解极性没有明确表达。** C2、C7、C8 使用无极性 C 符号，当前 pad 1 在 GND、pad 2 在相应正电源。若直接换成“1脚为正”的电解封装会反装。改有极性符号、旋转到正确方向，逐脚确认正端接正电源；若选无极性陶瓷则在 BOM 明确。

**S12：供电标记需在真实供电关系确定后整理。** ADC_5V 经 FB1 这种无源器件供电，原生 ERC 可能需要合适的 PWR_FLAG 声明。主 5V 合网后清理重复标记，不能靠增加标记隐藏断线。

### 5.1 修改顺序

1. 备份原理图，按现有实际位号操作。
2. 统一主电源 `+5V`，保持 `ADC_5V` 分支。

## 六、样机测试与验收顺序

| 阶段 | 方法 | 通过条件/记录要求 |
|---|---|---|
| 断电检查 | 万用表检查电源轨阻值、插座方向、二极管方向及电容极性 | 无非预期短路；不得用通电碰运气代替 |
| 单电源上电 | 使用限流电源，先不接测量输入及电脑 | 测得主 5V、ADC_5V、3.3V，记录静态及显示/通信工作时变化，无异常发热 |
| 数字链路 | 逻辑分析仪或示波器看 CS/CLK/DI/DO | 双通道选择正确；100kHz 起步；读数时序和高低电平裕量合格 |
| 模拟缓冲/RC | 分别测 VIN、BUF、ADC 端；施加小幅阶跃 | 无明显自激；ADC 端体现 RC 响应，两路相符 |

| 通道串扰 | CH1 固定、CH2 做 0↔5V 变化，再交换 | 报告另一通道的额外偏移/噪声；建议以不超过约 1LSB 额外变化作为初步观察目标，最终按课程要求 |
| 采样和上传 | 基于 MCU 时间戳、序号统计至少 60秒 | 每通道采样率符合设定，双通道同帧，正常界面 ≥20Hz，记录丢帧 |
| N 窗口实验 | 固定 fs，同一原始数据比较五组，再做实时核对 | 原始数据可复算；列均值、标准差、峰峰值、响应时间 |
| 误接保护 | 在限流、可监测电源轨的条件下逐步升至目标故障电压 | 先核算再实施；写明供电状态、持续时间、两路同时情况；故障后准确度恢复 |
| 接口供电 | 分别测试外部电源、USB-UART 接入以及允许的组合 | 无未设计的稳压输出并联/反向供电；未验证的组合不列为支持 |
| 整机 | 装壳后重复噪声、串扰、接插件与长时间运行 | 装配不引入新故障；铜箔绝缘及单点接地可靠 |

保护测试不能把“没有立即损坏”等同于满足全部条件；断电保护若未设计和验证，应明确不属于保证范围。

## 七、最终判定

- **报告：修改后可作为课程实施基线；核心架构无需推翻。**
- **原理图：当前不通过进入 PCB 阶段的审查。优先处理 S01～S05 的实际连接错误，再解决符号封装及供电接口。**
- **性能：输入阻抗、全量程误差、端点、串扰和保护能力均待样机实测，不填写虚构通过结果。**

# V2.3逐节点连接表

**这是连接清单，不是采购BOM或实物接线验收。** 电路图符和蓝图有64项，183个已接电路引脚，47个命名网络；5个引脚明确NC。新增3个手动供电声明标记如下，原生XML和本CSV均不将它们当作采购元件。

| 标记 | 声明网络 | 正常供电依据 |
| --- | --- | --- |
| #FLG001 | USB_SAFE | J1 VBUS→F1→MUX IN1 |
| #FLG002 | EXT_SAFE | J2→F2→Q1→MUX IN2 |
| #FLG003 | VANA | MUX OUT→SYS_5V→R4 |

这只解决ERC的电源来源声明，不阻断任何反灌路径，P0仍未关闭。

M1编号是逻辑端点，不是Blue Pill排针编号。Q1的G/S/D、Q2的B/C/E是功能端子。D1～D4仅独立二极管占位；若采用BAV199，须重新映射其两个管和共用脚，不可直接套封装。

同名标签在单页内电气相连，不能把没有长线跨图误判为断路。自定义单单元IC图符按手册已知引脚建立，只作为待复核草案；所有Footprint为空。

## 明确不连接

`U3.11`, `U5.1`, `U5.2`, `J1.2`, `J1.3`

U5.2(D0)采用内部上拉自动模式候选，U5.3接GND；U5.1(STAT)不使用；U3.11为禁用第四路输出；J1.2/3是电源专用USB-B的D-/D+。NC不等于内部无电流，仍需数据手册和上电状态核验。

## 用途及依据

- INPUT_CH0/1→180k→SENSE_CH0/1，1.2M到GND；提供无偏置分压与输入负载。
- SENSE→MCP6002同相输入；BUF_CH0连接U2.1/2，BUF_CH1连接U2.6/7，为本路跟随反馈。
- BUF→220Ω→ADC_CH0/1，100nF接GND；候选输出隔离/滤波，动态尚未验收。
- D1/3的K接输入节点、A接地；D2/4的A接输入节点、K接VANA；器件漏电和保护协调仍BLOCKED。
- USB_SAFE/EXT_SAFE→TPS2115A→SYS_5V；SYS经1Ω给VANA，VANA经4.7k泄放。
- 3V3经68Ω给TL431B阴极与REF；阳极接地。REF经1k给MON_REF；VANA经10k/10k和1k给MON_VANA。
- MCU_CS/CLK/DI经过AHCT缓冲与100Ω串联驱动ADC；DO经LVC降至3.3V域。
- MCU_BUF_ENABLE_H通过NPN基极10k驱动，100k下拉；OE由10k上拉VANA，MCU高电平启用，复位高阻禁用。
- UART与SWD仅功能接线；没有真正的掉电隔离，不得将无电源针当作无反灌证明。
- OLED口是可选端点；PB6/PB7映射、模块现有I2C上拉及供电顺序需验证，本稿未实现完整OLED外设隔离。

## 2. 项目设计基线

本项目是一台课程级双通道数字电压表：

- 两路 `0～5V DC` 单端输入；
- 两路共地、非隔离；
- STM32F103C8T6 Blue Pill 控制；
- ADC0832 双通道 8 位 ADC；
- MCP6002 双运放作为输入缓冲；
- 74AHCT125 完成数字接口缓冲/电平转换；
- OLED 显示；
- UART 与上位机通信；
- BNC 为面板安装，通过短同轴线连接 PCB 上的两位端子；
- 主电源为稳定 `+5V`，Blue Pill 提供/使用 `+3.3V` 逻辑电源；
- ADC 使用经 FB1 滤波后的独立 `ADC_5V` 支路。

名义 ADC 分辨率：

`5V / 256 = 19.53125mV/LSB`

推荐的课程验收目标是室温、预热和校准后，全量程误差不超过约 `±50mV`；这只是待验证目标，不是现阶段已获得的实测性能。

输入保护只能描述为有限的误接保护设计。设备外壳应标注：`0～5V DC、共地、非隔离`。在专项测试完成前，不得把 `±12V` 写成无条件保证。

## 3. 已确定的电气结构

### 3.1 两路模拟前端

每路结构应保持对称：

1. BNC 中心线进入 PCB 两位端子的信号脚；屏蔽层连接系统 GND。
2. 输入信号经过 `10kΩ` 串联限流电阻。
3. 输入节点通过 `10MΩ` 接 GND，形成高输入阻抗默认状态。
4. 输入节点用两只 1N4148 向 `+5V` 和 GND 钳位。
5. MCP6002 接成电压跟随器：输出直接反馈至本通道反相端。
6. 运放输出经过 `3.3kΩ` 串联电阻后进入 ADC 输入节点。
7. ADC 输入节点通过 `1uF` 接 GND，形成约 48.2Hz 的一阶低通。

关键要求：运放输出网和 ADC 输入网必须分开，`3.3kΩ` 不得被导线旁路；运放反馈不得跨过 `3.3kΩ`。

建议网络名：

| 功能 | 通道 1 | 通道 2 |
|---|---|---|
| 运放输出 | `BUF_CH1` | `BUF_CH2` |
| ADC 输入 | `ADC_CH1` | `ADC_CH2` |

### 3.2 ADC0832 与电源

- U1：ADC0832，PDIP-8。
- 主 `+5V` 经 FB1 到 `ADC_5V`。
- C2 `10uF` 和 C3 `100nF` 应在 `ADC_5V` 与 GND 之间。
- ADC 的供电也影响参考范围，因此 FB1 默认应使用低直流电阻磁珠；若改用电阻，必须重新评估压降和满量程误差。
- 建议在实际 ADC 电源脚处测量并记录电压。

### 3.3 数字接口与 74AHCT125

U2 使用 74AHCT125，供电 `+5V`：

- 三路用于 STM32 到 ADC 的 `CS`、`CLK`、`DI` 缓冲；
- 第四路用于缓冲 ADC 的 `DO`；
- 所有 `/OE` 为低有效，固定使能时应连接 GND；
- U2 电源单元必须正确连接：VCC 至 `+5V`，GND 至 GND；
- C6 `100nF` 应靠近 U2 电源脚放置并跨接 `+5V` 与 GND。

推荐并已经人工采用的网络：

| 网络 | 用途 |
|---|---|
| `ADC_CS_3V3` | STM32 控制侧 CS |
| `ADC_CLK_3V3` | STM32 控制侧 CLK |
| `ADC_DI_3V3` | STM32 控制侧 DI |
| `ADC_DO_5V` | ADC DOUT 至 U2D 输入 |
| `ADC_DO_BUF_5V` | U2D 输出至分压上臂 |
| `ADC_DO_3V3` | 10k/20k 分压中点至 STM32 |

默认状态电阻当前设计为：

| 位号 | 数值 | 连接要求 |
|---|---:|---|
| R11 | 100kΩ | `ADC_DO_5V` 下拉至 GND |
| R12 | 10kΩ | `ADC_CS_3V3` 上拉至 `+3.3V` |
| R13 | 100kΩ | `ADC_CLK_3V3` 下拉至 GND |
| R14 | 100kΩ | `ADC_DI_3V3` 下拉至 GND |

DO 返回路径应为：

`ADC0832 DOUT → ADC_DO_5V → U2D → ADC_DO_BUF_5V → R7 10kΩ → ADC_DO_3V3 → STM32`

分压中点通过 R8 `20kΩ` 接 GND。

### 3.4 UART、OLED 与外部接口

- J4：OLED 四针接口，实际模块针序必须核对；I²C 上拉 R9/R10 为 4.7kΩ，若 OLED 模块已经带合适上拉，可标为选装/DNP。
- J5：UART 四针接口，默认只使用 GND、TX、RX；剩余电源脚默认 NC，避免两个电源互顶。
- J6：两位主电源输入端子。
- J7/J8：两路面板 BNC 转接端子，每个端子一脚信号、一脚 GND。

## 5. 当前仍需完成或重点核验的事项

### 5.1 阻塞 PCB 的关键事项

1. **J1 Blue Pill 引脚映射**：现有 J1 是通用 2×20 符号。必须逐脚建立“J1 编号—Blue Pill 实际丝印名称—原理图网络”的映射，尤其先核对 `+5V`、`+3.3V` 和 GND。错误映射可能导致模块损坏。
2. **J1 自定义封装**：不得直接使用普通 `PinSocket_2x20_P2.54mm`，因为两排距离通常不匹配 Blue Pill。
3. **C2/C8**：必须确认值为 `10uF`，符号为 `Device:C_Polarized`，正极接正电源，负极接 GND，并使用 D5.0/P2.00 封装。
4. **C6**：确认 100nF 去耦存在并设置正确封装，且靠近 U2 供电脚。
5. **ERC**：完成上述项目后运行 ERC。不得把 PWR_FLAG 当成真实连线。

### 5.2 必查接口

- J4 的 VCC/GND/SCL/SDA 顺序必须和将购买的 OLED 模块一致。
- J5 的 GND/TX/RX 顺序必须和 USB-UART 模块一致；TX/RX 交叉关系按实际模块核对。
- J6 必须确认端子 1/2 与 `+5V`/GND 的对应关系，并在丝印标注极性。
- J7/J8 必须确认信号脚和 GND 脚，并在 PCB 丝印标注 CH1/CH2、SIG/GND。
- 所有有极性电容和二极管应同时检查原理图方向、焊盘 1、PCB 丝印方向。

### 5.3 电气检查

- 检查 R5/R6 是否确实串接在 `BUF_CHx` 与 `ADC_CHx` 之间，没有隐藏旁路。
- 检查 MCP6002 两个跟随器反馈仅从本通道输出回本通道反相输入。
- 检查 U3 电源单元 VDD/GND 和 C5。
- 检查 U2 四个 `/OE` 均处于确定状态；若固定使能，应接 GND。
- 检查 U2D 的输入、输出没有接反。
- 检查 R7=10kΩ 为分压上臂、R8=20kΩ 为下臂。
- 检查 ADC0832 所有未使用或模式相关引脚的状态符合所采用的单端双通道模式。
- 检查所有网络标签完全一致，不混用 `3.3V`、`3V3` 或不同标点。
- 检查 NC 标志只放在确实不用的脚上。

## 7. 原理图完成后的模块化整理

电气连接和 ERC 通过后，再整理版面。优先采用单页功能分区，避免在尚未稳定时引入层次图迁移风险。

建议分区：

1. 电源输入、滤波与保护；
2. 通道 1 输入、钳位、缓冲和 RC；
3. 通道 2 输入、钳位、缓冲和 RC；
4. ADC0832 与 ADC 电源支路；
5. 74AHCT125 电平转换与默认状态电阻；
6. STM32 Blue Pill；
7. OLED、UART 和外部接口。

整理规则：

- 信号总体从左向右，电源从上向下；
- 两个模拟通道上下对称；
- 电源去耦放在对应 IC 电源单元附近；
- 长距离连接使用清晰、唯一的网络标签；
- 不要为了视觉整洁删掉必要的电源符号或 GND；
- 用图形框和文字标题标明模块；
- 整理前后比较网络表，确保只改变位置和绘图，不改变连接。

如果后续确实需要层次化原理图，可在单页版本验证完成后，将上述七个区域逐步迁移到子页，并使用层次标签连接。

- DRC 不存在未解释的错误。
- 模拟输入和 ADC 区域远离 CLK、OLED 和其他高速数字走线。
- 保持连续 GND 参考面；不要让数字回流穿过高阻模拟区。
- C3/C5/C6 紧靠对应 IC 电源脚。
- BNC 转接端子、主电源端子、Blue Pill USB、OLED 和 UART 均有明确丝印。
- 有极性器件丝印清晰。
- 增加 +5V、ADC_5V、+3.3V、GND、BUF_CH1/2、ADC_CH1/2、CLK 和 DO 测试点。

### 10.3 首次上电

1. 不插 U1/U2/U3 和 Blue Pill，先测量电源输入无短路。
2. 限流电源供电，确认 +5V、ADC_5V、+3.3V（若由模块产生）的电压和极性。
3. 分阶段插入芯片/模块并观察静态电流。
4. 无输入时检查两路模拟节点没有异常饱和。
5. 先用 0～1V 小信号验证，再逐步提高到 5V。
6. 校准后测试 0、0.5、1、2、3、4、4.5、4.9、5.0V，并记录 ADC 原始码、显示值和标准表读数。
7. 端点附近出现饱和时，不得试图仅靠软件标定掩盖。
8. 误接保护试验必须使用限流源、逐步升压，并监视电源轨注入电流和器件温度。

## 11. 当前结论

现有方案不需要推翻重画。经过已经完成的供电网络、RC 旁路、电平转换和封装修正后，核心拓扑具备实现可用样机的基础。

当前最大未闭合风险是：

1. Blue Pill 的 J1 编号、实际模块引脚和自定义封装是否完全一致；
2. C2/C8 的极性、数值和封装是否已经在最新文件中正确保存；
3. ERC 尚未作为最终文件的通过证据；
4. PCB 布局、DRC 和实物样机尚未验证。

在这些项目关闭前，原理图不能标记为“最终可投板”；关闭后可以进入 PCB 布局和样机验证阶段。

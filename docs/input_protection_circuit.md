# V2.2输入保护与断电路径

**状态：BLOCKED—功能连接和泄放预算已给出，准确二极管/温度/内部注入仍未闭环。** 不保证高压误接、ESD或市电安全；仅研究低压共地0～5V正常输入及本板断电而输入存在。

## 1. 每通道准确功能网络

```text
J_CHx SIG ─ R_S=180kΩ/1% ─ N_SENSE ─ MCP6002同相输入
                              │         反相输入与本路输出短接
                              ├─ R_G=1.2MΩ/1% ─ GND
                              ├─ 可选R_B=10MΩ ─ VANA（默认DNP）
                              ├─ D_LOW阴极；D_LOW阳极接GND
                              └─ D_HIGH阳极；D_HIGH阴极接VANA
MCP6002输出 ─ 220Ω ─ ADC_CHx ─ 100nF ─ GND
MCP6002 VDD与ADC VCC接VANA；GND共地
VANA ─ R_BLEED=4.7kΩ/1% ─ GND（两路共用）
```

候选1N4148 DO-35或低漏电双二极管BAV199；不能用BAT54等低VF肖特基的便利性代替高阻漏电核验。BAV199双管串联的封装脚位在独立资料核验后再写入，不凭功能方向直接推断物理脚序。

- R_S位于接口后，限流及分压；工作电压、脉冲能力仍按准确电阻系列核查。
- 两只外部二极管提供正/负异常的候选电流去路，**外部硅二极管不保证比内部ESD先导通，也不能自动保证N_SENSE在VDD±0.3V内**。内部/外部共同导通时必须按器件允许的钳位电流核算。
- VANA泄放是明确的吸收负载，接在1Ω模拟支路之后，不能只接SYS上游再假设吸收同样有效。
- TL431不替代R_BLEED：低于其调节电压时不保证有吸收能力，断电轨约0.25V不能靠2.495V基准泄放。
- 默认无偏置不等于无断电反灌。MCP6002正向ESD结构不是普通到VDD的二极管；4.1.2明确建议外部输入→VDD二极管和负向限流。不能由通用运放模型推断其内部在VDD+0.3V导通；本稿电流去路优先指外部D_HIGH，内部/输出行为保持待验。

## 2. 上电正常测量

Vin=0～5V，名义节点0～4.348V；二极管应基本截止。高阻节点的净漏电和PCB漏电方向均可能影响读数。

无偏置网络Rth约156.522kΩ，输入折算漏电误差简化为`R_S×I_net`：30nA分配约5.4mV，100nA约18mV。不能把某个二极管25°C单点漏电最大值用作双二极管+运放+板面的全温总上界。

R_G和R_S容差角点可满足理想≥1MΩ，但真实增量输入负载包含保护漏电随电压的变化。测量应区分被测电路开路电压与已经接上本仪器后的端口电压；高源阻抗会造成负载扰动。

有偏置DNP安装后，重算流向和噪声，并更新BOM版本；当前无偏置脚本不能自动给有偏置方案背书。

## 3. 本板断电，输入保留5V

功能路径：SIG→180k→外部D_HIGH→VANA→4.7k→GND。MCP6002内部正向ESD/输出的其他路径不能当成已知同等钳位，须单独核验。用最保守零二极管压降、忽略R_G和芯片静态负载，求只含输入钳位的DC上界：

`VANA_off ≤ Σ(Vin_i/Rs_i) / (1/Rbleed + Σ(1/Rs_i))`

只对实际正向导通的输入支路求和；不能把0V输入的反偏上钳位当作吸收电流路径。脚本已处理导通集合。

| 工况 | 1%角点保守DC上界 |
| --- | --- |
| 两路0V | 0V |
| 一路5V、另一路0V | 0.129737V |
| 两路5V | 0.252912V |

两路5V nominal为0.248152V；单路注入绝对粗上界5/(180k×0.99)≈28.1µA，两路总≤56.2µA。正常供电R_BLEED在5.25V、-1%阻值下耗约1.128mA、5.92mW。

### 成立前提和未解决事项

- 只有两个≤5V信号注入；R_S和R_BLEED正确安装、容差和工作额定成立。
- 电源入口、SWD/TTL、PA0监测或其他数字脚无额外注入，储能电容已充分放电。
- 钳位模型只建立单向电流路径，不模拟内部晶体管、锁存、瞬态、热效应或二极管正向压降。
- 0.253V是VANA节点DC上界，**不是所有电源轨、所有引脚或过渡过程的统一上界**。受保护节点本身可比VANA高一个二极管压降；内部注入是否合规须查原厂，而不是与0.3V简单比较后宣布通过。
- 二极管的额定/内部保护允许值仍需闭环；电流虽小，也不能由此宣称“完全没有部分上电”。

## 4. 测试与临时合格定义

| 工况 | 观察 | 定型前判据 |
| --- | --- | --- |
| 正常0/0.1/0.2/1/4.9/5V | 端口电流、缓冲输出、原码 | 增量负载≥1MΩ，端点单调，漏电预算和允许误差成立 |
| 热态、清洁/污染、湿度 | 输入漏电、码漂 | 不把常温器件值当全板保证；环境范围须先冻结 |
| 断电单路/两路5V | VANA、SYS、3.3V、各钳位电流 | 条件稳态VANA建议≤0.30V；每芯片实际电源/注入符合资料，无部分启动，不能只看VANA |
| 上电/掉电时输入不变 | 全电源轨和输入输出瞬态 | 所有状态符合工作/绝对最大区间；未冻结时不得验收 |
| 信号短时异常 | 脉冲幅值、持续时间、保护电流 | 必须先定义脉冲源阻抗/能量，再规定试验；本稿不承诺12/24V保护或标准ESD通过 |

建议≤0.30V只是被动泄放方案的候选观察阈值，不证明芯片必然无寄生工作。首轮实测先限流，使用已确认允许共地的低压源，禁止市电或浮地高压对象。

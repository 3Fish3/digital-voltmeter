# V2.1电源草图与前端预算

**阶段：工程候选，供审查；不是已冻结原理图或采购清单。**

本轮承接V2.0-R0外部审查：优先解决电源压降和5V输入余量，比较有/无偏置前端。旧KiCad工程未修改，本稿不是新版ERC/DRC结果。器件供货、保护、动态切换及实物端点仍未验收。

## 1. 本轮结论

1. 原120kΩ前端在模拟供电低时高端余量不足，建议将串联电阻改为180kΩ候选，保留1.2MΩ下拉。
2. 先评估不升压的简化电源基线，但它只改善供电选择和滤波，**不是精密参考方案**；无法凭此承诺高准确度。
3. TPS2115APW作为自动MUX候选；它比直插元件难焊、供货未核实，不以“常见”名义直接冻结。比较手动机械选源作为更易买的备选，需用户决定自动/手动取舍。
4. 无偏置前端更符合普通被动输入阻抗直觉；有偏置可留低端余量，但会注入电流，必须确认课程定义。两者均未解决所有端点及断电保护问题。
5. 下述4.63V最低VANA来自**条件预算**，不是已实现保证。若接口最低电压、电流或路径电阻不能满足预算，应修改方案，而非修改验收条件来宣称通过。

## 2. 已取得数据手册

- [TI TPS2114A/TPS2115A SBVS044F](../references/datasheets/tps2115a.pdf)：已读引脚、真值表、电气特性和自动/手动模式、反向导通说明。TPS2115APW为TSSOP-8，不是DIP。电源工作条件见手册，正常两路5V使用；单输入也需符合内部VDD工作要求。
- [AOS AO3401A](../references/datasheets/ao3401a.pdf)：P沟道MOSFET，SOT-23；VGS绝对最大±12V；25°C、VGS=-4.5V下RDS(on)最大60mΩ，-2.5V下最大85mΩ。此值不能直接当全温最大值，热态阻值需另留预算/验证。
- [ADC0832-N](../references/datasheets/adc0832-n.pdf)、[MCP6002](../references/datasheets/mcp6002.pdf)：沿用已核验版本；准确采购厂商仍须锁定。

数据手册不保证PCB性能或市场库存；最终BOM不能用这里的候选替代供应核验。

## 3. 电源连接草图

```text
USB-B VBUS ─ F_USB(候选) ─ USB_SAFE ───────────────┐
USB-B GND ─ GND                                  │ IN1
                                                  ├─ TPS2115APW ─ SYS_5V ─ Blue Pill 5V
外部端子 +5V ─ F_EXT(候选) ─ Q_REV ─ EXT_SAFE ─────┘ IN2          │              └─ 模块3.3V
外部端子 GND ─ GND                                             │
                                                               └─ R_A=1Ω ─ VANA
                                                                               ├─ ADC0832
                                                                               ├─ MCP6002
                                                                               └─ AHCT125(若保留)
GND：共地连续回流，不通过电源选择器切换地。
```

- F_USB/F_EXT用于故障隔离，精确保险丝料号未冻结；自恢复保险丝热态电阻可能很大，不能只看额定电流。
- Q_REV仅在外部接线端子支路使用，防止正确使用范围内的反极性接线损坏。候选AO3401A反接保护：**D接保险丝后的外部输入，S接EXT_SAFE，G经100kΩ接GND**。正向上电先由D→S体二极管建立电压，再由负VGS导通。具体1/2/3物理编号必须根据原厂封装图二次确认后才画图；不凭同名库推断。
- 单只Q_REV导通后是双向通道，**它不是理想二极管，也不单独提供完整反向阻断**。两源隔离主要由MUX实现，须核验实际反向条件。
- SYS_5V、VANA各有就近电容；R_A候选1Ω/1%，限制的是模拟支路20mA预算，不把全板250mA串进该电阻。
- 输入各先设100nF，OUT候选10µF，VANA候选100nF＋10µF；这些仅为草图值，容量/ESR、热插拔与启动均须验证，不先加任意大电容。
- VANA上AHCT开关电流仍可能影响ADC参考；局部去耦、源端串联阻尼及实测要证明合理。若迁至数字5V支路，另算其输出超过ADC供电时的注入，不能只换电源网名。

### 3.1 TPS2115APW逐引脚候选

| 脚 | 名称 | 草图连接 |
| --- | --- | --- |
| 1 | STAT | 暂不接主控、标NC；后续需要状态时上拉到3.3V，核查掉电路径 |
| 2 | D0 | 自动模式需要高；候选不外接，利用手册规定的内部上拉；若改外部上拉须保证只接有电且合规的电平域 |
| 3 | D1 | 接GND，配合D0高选择自动模式 |
| 4 | ILIM | 经名义700Ω到GND，候选680Ω＋20Ω串联，1%；不是板子正常耗电设置 |
| 5 | GND | GND |
| 6 | IN2 | EXT_SAFE，100nF到GND |
| 7 | OUT | SYS_5V，候选10µF到GND |
| 8 | IN1 | USB_SAFE，100nF到GND |

自动模式选择**两路电压较高者**，不是默认USB优先或外部优先。切换受输入比较器约0.1～0.2V迟滞及10～50µs去毛刺时间影响，近等压时可能保持原选源，不保证瞬时始终连接较高者。D0/D1最终实现需在上电只接IN1、只接IN2和两者均有电时验证。

手册700Ω测试点：TPS2115A限流典型约0.71A，范围约0.47～0.99A；实际1%串联电阻并不是精确700Ω，不能把该测试点范围当作完整误差保证。限流下限应高于启动/峰值需求，上限仍须满足来源和保险丝设计。**0.25A正常预算不等于芯片硬限流到0.25A，也不满足任意USB端口要求。**

### 3.2 反向阻断的实际边界

手册说明：未导通的MOSFET无并联体二极管，切换时防止交叉导通；从高电压源转到低电压源，会等待输出与输入接近后接通。但明确写有：一旦接通，开关保持连接，不依输出电压再决定连接。

因此不能仅凭产品页“Reverse current blocking”推断任何外部抬高SYS_5V、输入突然下降或不同上电顺序都无回流。需要测试：

- 两个源独立、同时、各自拔出/下降；
- 输出储能电容对选中源的短时回流；
- Blue Pill USB、SWD供电、TTL供电等绕过MUX的路径。

本设计不允许由这些旁路主动给SYS_5V供电。Blue Pill原生USB需实际隔断VBUS路径或可靠结构限制，不能只靠注意事项作为最终闭环。SWD的3.3V脚是电压参考、TTL接口仅TX/RX/GND；仍须评估有信号而板掉电的I/O注入。

### 3.3 常见器件备选：手动选源

另一可评估结构是先保护两路，再用明确规格的**先断后合SPDT选择开关**把其中一路接SYS_5V，地始终共用。不用芯片自动选择，可降低供货/焊接门槛；必须核验触点电阻、直流额定与先断后合特性，不能泛指任意拨动开关。

代价：切换可能复位，不能自动无缝切换，已选中的电源也不会天然具有输出反向阻断。不能在用户未确认这些接口/行为取舍前替换MUX。

## 4. 条件电压与功耗预算

### 4.1 输入和负载分配（尚未实测）

| 条件 | 分配值 | 性质 |
| --- | --- | --- |
| 本板USB/外部入口电压 | 4.75～5.25V | 设计条件，测在本板接口而非适配器标签；长线/弱USB口不保证满足 |
| 全板峰值预算 | ≤250mA | 分配目标，含启动；不是已有固件/模块实测 |
| 主控及核心板 | 预留200mA | 预算，须实测克隆板及温升 |
| 可选OLED | 预留30mA | 预算，按实际屏幕复核 |
| 模拟ADC/运放/AHCT等 | 预留20mA | 预算，含逻辑切换、去耦瞬态和可能吸收负载 |
| 保险丝/连接器/反接管/走线总电阻 | 每个有效输入路径≤0.25Ω | 设计分配，待料号与热态验证，不是保证值 |
| TPS2115A导通电阻 | 0.15Ω预算 | 手册热态测试条件最大值；实际温度/输入条件适用性复核 |
| 模拟串联滤波 | 1Ω、20mA | 候选，上述20mA预算适用于此支路 |

`SYS_5V_min = 4.75 − 0.25×(0.25+0.15) = 4.65V`

`VANA_min = 4.65 − 0.020×1.01 = 4.6298V ≈ 4.63V`，已计入1Ω电阻的+1%容差。下文4.63V表格为近似展示，脚本另包含4.6298V工况。

上限不能靠压降保证降低：轻载VANA可能接近5.25V，正常范围按4.63～5.25V预算。该范围满足名义ADC/AHCT工作范围交集，但**不替代纹波、瞬态及前端余量预算**。

在这个预算下MUX导通损耗约0.25²×0.15=9.4mW；输入路径损耗预算15.6mW；模拟1Ω电阻20mA下0.4mW。故障限流、短路及启动损耗不等于上述正常功耗，须单独热预算。

本板接口若只有4.4V，则同样预算VANA约4.28V，ADC/AHCT正常工作条件失败；分压改小也不能补救芯片电源不足。若器件热态电阻超过分配，或本板必须接受这类低USB电压，就需重新设计电源架构。

### 4.2 USB条件

本稿可选基线使用合适5VUSB电源适配器，不能默认未枚举电脑数据口提供250mA。若必须把电脑USB口作为供电源，需明确USB版本、供电协议/枚举或另加合规控制，并重新预算；本稿USB-B D+/D−标NC不满足一般数据设备枚举设计。

“≥20Hz上位机”仍可通过另一USB-TTL连电脑，TTL不提供电源，必须共地。输入地因此可能与电脑地连接，禁止测量不允许共地的对象。

### 4.3 参考漂移风险

该简化路线没有实时准确测VANA，也没有稳压为精密参考。偏置网络中`
Vin=(VANA/α)(Code/256−β)`仍需要实际参考值。

若只按5V换算，理想Vin=5V而VANA=4.63V，读数可达约5.40V；若VANA=5.25V，可读约4.76V（未计量化）。无偏置时同样有5/VANA比例误差。端点不削顶与读数准确是两件事；不允许通过把显示值裁剪到5V来掩盖参考误差。

**路线A不能以“高性能/高精度”定稿**。若接受条件电源和量化级测量，必须声明漂移误差；若要求USB与外部切换后仍有可信读数，需要：

- 有明确准确度和动态漂移预算的模拟稳压；或
- 有校准参考的VANA测量/补偿电路。STM32内部ADC仅作为电源监测候选，不替代课程ADC0832采集；内部参考典型值不能自动作为准确基准。

这两项尚未定型，不能在本轮加入未经资料核验的基准芯片和接线。升压＋LDO仍是备选，不因简单路线有问题就立即套用低噪声但输出容差较大的LDO。

## 5. 两种前端对比

候选共同部分：输入经R_S到N_SENSE，R_G到GND，MCP6002跟随器，输出220Ω＋100nF接ADC。有偏置再加10MΩ至VANA。所有阻值以下按1%角点；未计保护漏电、运放失调和板面泄漏。

| 参数 | 原120kΩ有偏置 | 新180kΩ无偏置 | 新180kΩ有偏置 |
| --- | --- | --- | --- |
| R_G/R_B | 1.2MΩ/10MΩ | 1.2MΩ/不装 | 1.2MΩ/10MΩ |
| 输入最坏增量阻抗 | 1.180MΩ | 1.366MΩ | 1.239MΩ |
| VANA=4.63V，5V输入最坏节点 | 4.5545V | 4.3591V | 4.3633V |
| 相应最坏高端余量 | 75.5mV | 270.9mV | 266.7mV |
| VANA=5V，0V输入理想节点 | 54.0mV | 0V | 77.1mV |
| VANA=5V，0V输入注入 | 0.450µA | 理想0 | 0.428µA |
| VANA=5V，输入折算步长 | 21.72mV | 22.46mV | 22.81mV |

新值用稍低码值利用率换高端余量，**不是提高分辨率**。无偏置与有偏置各有问题：

- 无偏置：正常直流输入为被动到地1.38MΩ名义负载，定义简单；0V时要求运放输出贴地，可能有失调/低端死区，需试验，不能假定“轨到轨”就完美到0V。
- 有偏置：低端名义余量约77mV，不能直接用异条件输出摆幅规格保证；向被测源注入电流、依赖供电，课程是否接受仍未确认。
- 两者：高阻节点保护漏电可主导误差；新网络的源戴维南电阻更高，低漏电与清洁工艺更加重要。无偏置网络Rth约156.5kΩ，有偏置约154.1kΩ，100nA带来的节点偏移约15mV，不能只看到输入阻抗增加。
- 断电时不能因不装10MΩ偏置就认定无反灌，运放输入内部钳位仍存在。

**建议布局预留R_B，但保持审查决策未冻结。** 若课程按普通无源输入定义，优先无偏置；若低端死区无法接受且许可小电流注入，再采用偏置或其他经预算方案，不擅自添加负电源。

### 定型前测试

1. 实测两输入接口电压、电流及路径压降，证明预算4.75V/250mA/0.25Ω成立；不成立则返工方案。
2. 冷/热态验证Q_REV、MUX电压和功耗，反接时芯片输入不出现超范围负压。
3. MUX两源、拔插、近等压、输出带储能及下降源，记录反向电流和SYS/VANA/3.3V过冲/跌落；若自动选高电压引发参考跃变，明确暂停有效测量直到稳定。
4. MCU复位和断电有输入条件下，逐芯片验证电源与I/O注入。单只PMOS不能作为此项验收依据。
5. 两种前端0V、低端、4.9/5V单调性和输出余量；温度/漏电/清洁状态纳入测试。
6. 以真实输入电流和增量负载分别记录输入阻抗，不把偏置网络伪装成单一无源1MΩ。
7. 测VANA波动与固定输入码值变化，确定准确度声明及是否需要稳压或参考补偿。

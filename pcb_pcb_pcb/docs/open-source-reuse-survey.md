# 新版双通道电压表：开源复用调研

## 固定需求

- STM32与ADC0832必须使用；两路0～5V单极性直流测量，输入阻抗≥1MΩ。
- 优先常见直插器件；允许贴片和重新制板。
- 软件多次采样平均；完整双通道数据帧及上位机刷新≥20Hz。
- 同一数据帧用于双通道绘图和存储；五组平均次数对比降噪与响应速度。
- 两路外壳接口分区，降低串扰；低压共地，不是电气隔离。
- 支持外部与USB供电，需设计防回灌。未要求耐受12V、24V等误接。

## 检索与证据边界

本轮使用Exa进行英文、中文及GitHub/Gitee定向检索，分别查找ADC0832驱动、STM32电压表、高输入阻抗模拟前端、串口多通道绘图存储。
未找到经核验、完整满足全部要求的现成整套工程；这不等于此类项目不存在。
GitHub API出现限流，部分网页提取及源码下载出现TLS错误，未修改代理或安全配置绕过限制。可获得的证据按下表分级，不将搜索摘要当作源码验证。

## 推荐复用方式

1. **硬件自行按需求定型**：参考osillyscope的高阻缓冲思想，不搬其双极性量程、负电源或整套PCB。输入保护、0～5V端点、输入阻抗、双路布局及USB/外部电源防回灌必须重新核算。
2. **ADC驱动小范围移植**：以adc0832-wiringPi为时序参考，对照实际ADC数据手册编写STM32版本；明确独立DI/DO及错误状态，不把通信错误当作0V。
3. **上位机分阶段复用**：SerialPlot可先作串口与双曲线调试；正式程序优先评估RTGraph的MIT架构，取得并审查源码后再决定采用多少代码，不直接复制旧程序。
4. **课程实验自行实现**：五组平均次数可候选1、4、8、16、32；统一实验条件，记录平均次数、原始/平均结果、帧序号及时间信息，对比波动、阶跃响应和丢帧。
5. **采集语义**：ADC0832通道复用，不能硬件同时转换；成对采集两路，在同一帧绘图存储，并保留通道时间偏差信息。最大32次平均、20双通道帧/秒至少需1280次转换/秒，还需预算时序及通信开销。

# 掉电隔离候选方案调研记录（未采纳 / 归档备查）

**状态：用户明确该问题不增加硬件解决。操作上采用“先烧录调试，再断开调试器，使用独立电源测量”的分阶段流程。本方案归档备查，不纳入工程，不增加隔离芯片，不修改原理图。**

---

## 1. 调研背景与约束

原设想评估“主板完全掉电时仍允许带电调试器/串口物理连接”的硬件保护。用户已确认采用操作规程规避：
- 烧录阶段与独立供电测量阶段物理分开；
- 不在掉电状态下长期连接带电外设；
- 避免为低概率异常引入额外开关芯片、电源联锁及阻抗开销。

---

## 2. 器件特性梳理与局限性（备查）

此前针对 SN74CB3Q3245、TMUX1574 等开关器件的调研要点与局限如下：

1. **导通阻抗与寄生特性**：
   - 开关存在导通电阻（典型 2～4Ω）及极间电容（Cio 约数 pF 至十几 pF），对数 MHz 时钟沿和高速翻转并非绝对零损耗；
   - 模拟信号经过总线开关时，Ron 随输入电压、温度变化可能引入微小非线性，并非“完全无损”；
2. **掉电高阻与过渡区局限**：
   - 数据手册标注的 $I_{\text{off}}$ 仅保证在 $V_{CC}=0\text{ V}$ 稳态条件下的漏电，无法涵盖慢速掉电（$0\text{ V} < V_{CC} < V_{CC,\text{min}}$）期间控制逻辑电平不确定的瞬态导通区间；
   - 若要实现真正的硬件电源联锁，需外加大成本电压监控器（Power-Good），大幅增加系统复杂度。

---

## 3. 结论

**不采用总线开关方案。** 维持既有 64 元件受控原理图草案，通过分步供电的操作流程避免反灌，硬件设计重心收敛回模拟调理、ADC0832 时序与基准稳定性。
